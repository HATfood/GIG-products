# مجموعه محصولات بلوط

این بسته فقط بخش «۰۲ / مجموعه محصولات» را دارد؛ همراه با جزئیات هر محصول و گالری مرتبط آن.

## اجرا

فایل `index.html` را باز کنید. نصب پکیج، npm، بیلد یا اتصال اینترنت لازم نیست. عکس‌ها، فونت و داده‌ها داخل همین بسته هستند.

## قرار دادن روی GitHub Pages

۱. ZIP را استخراج کنید.
۲. تمام محتویات پوشه، شامل `index.html`، فایل‌های CSS و JS و پوشه `assets` را در ریشه مخزن قرار دهید. خود ZIP را بارگذاری نکنید.
۳. در مخزن به **Settings → Pages** بروید.
۴. در **Build and deployment** گزینه **Deploy from a branch** را انتخاب کنید.
۵. شاخه **main** و مسیر **/ (root)** را انتخاب و ذخیره کنید.
۶. پس از انتشار، از لینک ارائه‌شده در همان صفحه استفاده کنید.

اگر در مخزن دیگری در یک زیرپوشه قرار دهید نیز مسیر عکس‌ها درست می‌ماند، چون همه مسیرها نسبی هستند. پوشه `assets` باید کنار `index.html` باقی بماند. نام فایل‌ها و بزرگی یا کوچکی حروف را تغییر ندهید.

## فایل‌ها

- `index.html`: صفحه بخش مجموعه محصولات و پنجره جزئیات و بزرگ‌نمایی تصاویر.
- `style.css`: استایل بخش محصولات، طراحی واکنش‌گرا و افکت عمق تصاویر.
- `app.js`: جستجو، فیلتر، انتخاب بسته‌بندی، بارکد و گالری.
- `data.js`: داده‌هایی که صفحه مستقیماً می‌خواند. برای تغییر قیمت و مشخصات پایه، این فایل را ویرایش کنید.
- `data.json`: نسخه JSON همان داده‌ها، برای استفاده مجدد. ویرایش این فایل به‌تنهایی صفحه را تغییر نمی‌دهد.
- `assets/`: تمام تصاویر موردنیاز، فونت محلی و فایل اکسل اولیه برای دانلود.

## نکته داده‌ها

۹ محصول از اکسل اولیه وارد شده‌اند. قیمت‌های ورودی ریال هستند و برای نمایش تومان بر ۱۰ تقسیم می‌شوند. وزن کاپوچینو در اکسل ۲۸۰ گرم و روی تصویر ۲۲۰ گرم است؛ این تفاوت داخل جزئیات محصول ذکر شده است.

برای افزودن محصول جدید باید رکورد آن در `data.js` و مشخصات تصویری آن در `profiles` داخل `app.js` اضافه شود. این صفحه خرید یا پرداخت آنلاین ندارد.
